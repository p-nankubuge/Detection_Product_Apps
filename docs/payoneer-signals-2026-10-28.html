Resolution 830x800 with no taskbar, Windows, hotmail (residential proxies) — tightened missed

Tightened definition: fp_resolution = fp_available_resolution = 830x800 on Windows. A real Windows screen always loses height to the taskbar, so available = screen means injected values. The tightened rule keeps 100% of the 6,607 sessions (no 830x800 session on Payoneer had a different available resolution), so the chart is unchanged and nothing is lost. In the last 3 days 830x800 appeared on exactly one key across all of Arkose - Payoneer Login (159 sessions). vs normal Payoneer Windows traffic: 95% hotmail (baseline 5%), 48% 'en-EN' locale (0%), 3.9 sessions / 2.1 IPs per fingerprint (1.1 / 1.1), 16-core NVIDIA profile on a netbook-sized screen. CO/KR/JP/BR IPs with matching timezones but English-only browsers. Quiet on CLM since Oct 23, active on Login.
